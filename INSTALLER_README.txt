ZettelLocal 2.12.1 — сборка Windows-установщика
================================================

Что получится:
  dist-installer\ZettelLocal_Setup_2.12.1.exe

Установщик:
  • устанавливает ZettelLocal как обычное Windows-приложение;
  • создаёт пункт «ZettelLocal» в меню «Пуск»;
  • предлагает ярлык на рабочем столе;
  • запускает приложение после установки;
  • не требует прав администратора;
  • не требует Python на компьютере после установки;
  • сохраняет пользовательскую базу отдельно от программы.

Данные пользователя:
  %LOCALAPPDATA%\ZettelLocal\data\zettel.db

Поэтому новая версия установщика может заменить ZettelLocal.exe,
не затрагивая заметки. Удаление приложения также намеренно НЕ удаляет
пользовательскую базу.

КАК СОБРАТЬ
1. Распакуйте весь архив в обычную папку Windows.
2. Дважды щёлкните BUILD_INSTALLER.bat.
3. Для сборки нужен Python 3.11+ только на компьютере-сборщике.
4. Скрипт соберёт ZettelLocal.exe через PyInstaller.
5. Если Inno Setup 6 отсутствует и доступен winget, скрипт попробует установить его.
6. Готовый установщик появится в dist-installer.

ВАЖНО
Готовый ZettelLocal_Setup_2.12.1.exe не требует Python у конечного пользователя.
WebView2 обычно уже установлен в Windows 10/11. Если его нет, Windows-приложение
может запросить Microsoft Edge WebView2 Runtime.
