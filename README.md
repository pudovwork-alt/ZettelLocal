# ZettelLocal 2.12.1

**Локальная база знаний по методу Zettelkasten: заметки, связи, граф и персональный ИИ.**

Приложение на Python с русскоязычным интерфейсом. Работает на вашем компьютере, хранит данные в SQLite и открывается в браузере или отдельном окне Windows. Облачный аккаунт и платный API для основных функций не нужны.

## Что умеет

- Markdown-заметки с автосохранением, тегами, избранным и ежедневными записями.
- Вложенные папки, каталог заметок и скрываемые панели.
- Ссылки `[[Название заметки]]`, обратные ссылки и кнопка «Вставить статью».
- Граф заметок и сущностей; подтверждение и отклонение предложенных связей.
- «Картина темы»: связанные понятия, вопросы, действия, источники и пробелы.
- Оценка уверенности на основе материалов собственной базы — не проверка истинности фактов.
- Поиск похожих заметок, дубликатов и возможных противоречий.
- Локальная Skip-gram-модель для поиска и персональных векторов слов.
- Подключение Ollama для генерации ответов по материалам базы.
- Auto-Capture: выделение решений, гипотез, вопросов и задач из сообщений пользователя в локальном чате.
- Импорт PDF, DOCX, TXT, Markdown, HTML, CSV, JSON и RTF; резервная копия в ZIP.

Умные инструменты используют локальные модели и эвристики: предложенные связи и выводы требуют проверки человеком. Skip-gram не является большой языковой моделью.

## Скачать и запустить на Windows

1. Нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив.
2. Установите **Python 3.11 или новее**, включив «Add Python to PATH».
3. Откройте `START_WINDOWS.bat`.
4. При первом запуске дождитесь установки зависимостей; на этом этапе нужен интернет.
5. Откроется браузер с адресом `http://127.0.0.1:8765` (если порт занят, выбирается следующий).

Пока работает приложение, оставляйте окно запуска открытым. Остановка — `Ctrl+C` в этом окне.

**В репозитории находятся исходники и инструменты сборки, а не готовый установщик EXE. GitHub Pages для запуска Python-сервера не используется.**

### Запуск вручную

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py
```

## Данные и обновление

| Способ запуска | Где хранятся заметки |
| --- | --- |
| `START_WINDOWS.bat` / `python run.py` | `data/zettel.db` в папке проекта |
| Оконное приложение из `BUILD_SINGLE_EXE.bat` | `%LOCALAPPDATA%\ZettelLocal\data\zettel.db` |

Персональная модель хранится в подпапке `model` соответствующего каталога данных. Путь можно переопределить переменной `ZETTEL_DATA_DIR` для запуска сервера.

Перед обновлением сделайте резервную копию из интерфейса и сохраните каталог данных. Закройте приложение, замените файлы программы, **сохранив папку `data`**, затем запустите снова. При переходе с браузерного запуска на оконный EXE данные находятся в разных папках: переносите их отдельно при закрытом приложении.

Пользовательская база и обученная модель не включены в репозиторий. При первом запуске база создаётся автоматически. Не публикуйте резервные копии заметок вместе с кодом.

## Локальный ИИ

Без Ollama доступны заметки, каталог, граф, локальный анализ и обучение векторов на собственных текстах. Для генерации ответов установите Ollama, загрузите совместимую с вашим компьютером модель и укажите её имя в настройках ZettelLocal. Адрес по умолчанию: `http://127.0.0.1:11434`.

Если указать удалённый адрес сервиса вместо локального, запросы будут отправляться на этот адрес.

## Сборка для Windows

| Файл | Результат |
| --- | --- |
| `BUILD_SINGLE_EXE.bat` | Оконное приложение `dist/ZettelLocal.exe` |
| `BUILD_INSTALLER.bat` | Установщик `dist-installer/ZettelLocal_Setup_2.12.1.exe`; требуется Inno Setup 6 |
| `BUILD_WINDOWS_EXE.bat` | Папка `dist/ZettelLocal/` с консольным EXE; сначала запустите `START_WINDOWS.bat` |

Сборка выполняется на Windows и скачивает зависимости. Готовый EXE включает Python. Оконный вариант использует pywebview и системный веб-движок Windows.

## Структура проекта

- `app/main.py` — FastAPI, маршруты приложения и импорт/экспорт.
- `app/database.py` — SQLite и миграции.
- `app/ai_engine.py` — локальная модель и поиск.
- `app/smart_tools.py` — анализ заметок и сущностей.
- `app/static/` — HTML, CSS и JavaScript интерфейса.
- `run.py` — запуск в браузере; `desktop_launcher.py` — отдельное окно.
- `installer/` — сценарий установщика Inno Setup.

## Состояние версии

Основа — последний найденный архив `ZettelLocal_2_12_1_Setup_Builder.zip` от 7 сентября 2026 года. В нём присутствует исправление запуска оконного EXE при отсутствии `stdout`/`stderr` (ошибка форматтера Uvicorn).

При переносе обновлены документация и версия API; сборка EXE больше не включает базу из рабочей папки. Основная логика приложения сохранена.

Проверены запуск API на чистой временной базе, выдача интерфейса, создание/редактирование/чтение/удаление заметки и экспорт. Полная проверка интерфейса, Ollama и сборка Windows EXE в этой среде не проводились. Подробности — [проверка версии](docs/VALIDATION.md), предыдущие описания — [история](docs/HISTORY.md).
